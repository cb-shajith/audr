# Chargebee

A sink that delivers [AUDR](../../spec/SPEC.md) records to a Chargebee site's
usage-ingest batch endpoint, for Chargebee Usage-Based Billing.

| Language | Status | Distribution |
| --- | --- | --- |
| [Python](python/) | Pre-release `0.1.0a1` | `audr-sink-chargebee` |

See the [Python package README](python/README.md) for installation, routing, and delivery
semantics.
